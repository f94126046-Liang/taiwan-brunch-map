# 早安，台灣｜台灣早午餐地圖

一張持續收集台灣早餐與早午餐的互動地圖。依縣市、餐點類型或關鍵字探索店家，點選地圖標記與店家卡片即可查看對應位置和資料來源。

## 網站功能

- 依店名、地區、餐點和描述搜尋
- 依縣市與早餐類型篩選
- 地圖標記和店家清單互相連動
- 響應式版面，支援手機與桌面瀏覽
- 每筆地點提供資料來源連結，方便查核與更新

地圖為縣市層級的示意圖，標記不代表精確地址或 GPS 座標。營業時間、價格和供應狀況可能變動，造訪前請查看來源或店家最新公告。

## 專案結構

```text
.
├── AGENTS.md          # AI 協作規則、內容規格與維護方式
├── index.html         # 網站頁面結構
├── styles.css         # 視覺樣式與響應式版面
├── app.js             # 搜尋、篩選、清單與地圖互動
└── data/
    └── places.json    # 店家與地點資料
```

本專案使用原生 HTML、CSS、JavaScript 和 JSON，沒有建置流程或必要的第三方套件，可部署至 GitHub Pages。

## 本機預覽

首頁會透過 `fetch` 載入 JSON 資料，請使用本機 HTTP 伺服器預覽，不要直接以 `file://` 開啟：

```bash
python -m http.server 8000
```

接著瀏覽 `http://localhost:8000`。

## 新增地點

在 `data/places.json` 新增一筆資料，沿用既有欄位格式。每筆資料需要唯一的 `id`、縣市、地區、類型、簡介、示意圖位置和可查證的來源網址。未查證的地址、價格或營業時間請留空或標示「依店家公告」，不要猜測。

詳細的資料格式、用詞、來源和 AI 修改規則請見 [`AGENTS.md`](AGENTS.md)。

## GitHub Pages

此網站是靜態檔案，可從 GitHub repository 的 **Settings → Pages** 設定使用 `main` 分支的根目錄（`/(root)`）部署。部署完成後，GitHub 會在 Pages 設定頁顯示網站網址。
